# ff-intel

Daily Fantasy Football intel packet for a **10-team Superflex Half-PPR** Sleeper league (no kicker, no DST, $100 FAAB, 2026 NFL).

## Files

| Path | What it is |
|---|---|
| `ff-intel/latest.md` | Current manager-ready packet (always overwritten) |
| `ff-intel/latest.json` | Same intel, machine-readable for Grok Team Bots |
| `ff-intel/archive/YYYY-MM-DD.md` | Dated snapshot of that day's packet |

## League

- 10 teams, Superflex, Half-PPR
- No K, no DST
- $100 FAAB
- Platform: Sleeper
- Season: 2026 NFL

Trade values use a **1–100 Superflex** scale (not dynasty dollars). Starting QBs are premium.

Packets overwrite `latest.md` / `latest.json` and the same-day archive. The 2026-09-01 evening file includes Tuesday practice notes (Jeanty side work, Evans DNP / Australia ramp, Kittle warmer, Warren practiced) plus Cedric Tillman → NO PS.
